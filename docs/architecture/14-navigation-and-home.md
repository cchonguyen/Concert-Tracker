# Navigation and Home

Part of [ARCHITECTURE.md](../../ARCHITECTURE.md).


The header has three places: **Home**, **Library** and **Explore**. Library holds Summary (the list of your events, Library's first page), Table, Manage and Log. Log lists Recently deleted shows, with Restore, and every change you have made (`src/components/LogView.tsx`); Log is shown to members too, and each member sees only their own rows. Explore holds Agenda (its first page), Month, Heatmap, River (the four timeline views, each its own page), Map, Stats and Ranking (the people you have seen live). Manage is hidden for members who cannot see it (`canManage`), and Summary is shown instead when a member opens its address. `src/services/nav.ts` holds the model: which page belongs to which section, and the `?view=` names (`?view=table`, `?view=agenda`, `?view=ranking`). There is no `?mode=`: each timeline view is its own `?view=`. Old names do not redirect: `?view=timeline`, `?view=artists`, `?view=events` and any unknown value open Home. The subtab each section reopens on this device is in `liveArchive.subtabs` (localStorage, storage errors ignored). A remembered page that is no longer in the section, such as `timeline` from before the rename, falls back to the section's first page. Each page's icon is shared through `src/components/pageIcons.ts`, so cards, subtabs and the Menu match.

Page width: the Table is wide (`max-w-6xl`) and every other page, Map included, shares one reading width (`max-w-3xl`). The top bar and sub-tab row always use the Table's width (`max-w-6xl`), so they never change size when the page does. Ranking, Stats and Map open with a title line, and every page's one-line description is `PAGE_BLURB` (also the Home cards). Back to top (`BackToTop`) appears once a long page has scrolled one screen: Summary, Agenda, Month, Heatmap, Table, Stats, Map, Ranking and Manage.

On a phone the subtab strips show icons only; the open page keeps its name. Every icon has a title and an aria-label. On a phone's first visit to a section a one-line hint, "Tap an icon to switch pages.", shows for about six seconds or until a subtab is picked; `liveArchive.tabHintSeen` in localStorage stops it from showing again.

Home (`src/components/HomePage.tsx`) is the landing page. Its top is the one-line add box (`CaptureBar`, the same capture as stage 1 and unchanged), with Import a list under it. Under that, when the email check is set up, the ticket email card (`EmailCard`, copy in `src/services/copy.ts`) says what the browser check reads and keeps, with the Google "unverified app" warning and a "How it works" panel; its "What's saved" list must match `BrowserScan.tsx` and `packages/ticket-scanner`. Then seven feature tiles (`FeatureTiles`, the seventh is "Show friends your year", which opens the Share page in Library; in sample mode the page opens and its actions show the sample explainer) that each open the page where the feature lives: open for 0 to 4 events, folded at 5 or more, dismissed per tile or with "Hide these", and kept on the account (`user_settings` key `tips`, or `app_settings` for a single owner; `GET` and `PUT /api/me/prefs`, `src/server/auth/prefs.ts`), so they follow you to another browser. Read through `src/services/prefs.ts`, which also moves a browser's old `localStorage` copy to the account once (migration `0027_tips_and_milestones.sql`). "Show tips again" in the Menu and About clears them. Home opens with a headline and one line under it ("Every show you've ever been to, in one place.", or "Start with the last show you remember" when empty), and the add box label changes to "A name is enough. You can add the rest later." when there are no events. Above the page's own content, `Callout` (`src/components/ui/Callout.tsx`) shows one dismissible tip on Summary, Table and Manage (`copy.callouts`). Milestones (`src/services/milestones.ts`): when a show added in this session crosses 1, 10, 50, 100, 250, 500 or 1,000 shows you went to (`wentTo`), or an act you saw at an event you went to is the 100th distinct one (`distinctActs`, the same count as the Home artists tile; `ARTIST_MILESTONES`), `MilestoneCard` shows the card with confetti (inline canvas, no library; no confetti under reduced motion). Only the highest one crossed counts, a show card wins when a change crosses both, the page load never counts, and the highest one shown is kept on the account, one value for shows and one for acts (`milestone` key, `{ shows, artists }`, each moved up only, so an older browser cannot bring a card back; `src/services/prefs.ts`). No card shows until that is read. Below that, Needs you lists shows waiting for a yes or no (`homeSummary().toConfirm`), ticket emails to review, and lineups still researching; it hides when there is nothing to do. Then one card per page, grouped under Library and Explore, with a line about the page and a live number where there is a cheap one (events, cities, artists seen). With no events, the cards dim and the add box asks for one show you remember. Summary keeps its "Just added" and researching lists.

Quick add (`src/components/QuickAdd.tsx`) opens the same capture, email check and import from any page, as a popup. Desktop has a header button; phone has a floating + in the bottom corner; N opens it unless you are typing or a panel is open. Saving closes it and shows "Saved · Open" for six seconds.

The Menu (`src/components/ui/MenuButton.tsx`) holds Your account and Members (multi-user only), Your data as one row (Import, Export, Sheets for the owner; on a phone each shows its icon and name in the bottom sheet, and on desktop each is an icon that names itself on hover or focus, with no delay), and Theme as one row of icons (Dark, Light, System) above the accent colors. Import and Google Sheets panels are opened by `App`, so Menu, Table and Quick add show one copy at a time. The CSV download is shared in `src/components/DataActions.ts`. The Table keeps its own Import, Sheets and Export buttons.
